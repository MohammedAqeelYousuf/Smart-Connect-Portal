# 🎓 SmartCon – Smart Connect Portal for Colleges  

SmartCon is a centralized digital platform designed to simplify communication and management in colleges.  
It provides **role-based access** for students and administrators to streamline announcements, events, exams, placements, and feedback in one place.  

---

## 🚀 Features  

- Landing Page & Role-Based Login  
- Student Dashboard: Announcements, Events & Feedback  
- Exam Timetable & Leaderboard  
- Placement Data Submission (Student Side)  
- Admin Dashboard: Users, Announcements & Events  
- Admin: Feedback Review, Exam Scores & Placement Management  

---

## 🛠️ Tech Stack  
- **Frontend:** ReactJS, Bootstrap, CSS  
- **Backend:** JSON Server (mock API)  
- **Authentication & Routing:** React Router  
 
---

## 📂 Project Setup  

### 1️⃣ Clone the Repository  
```bash
git clone https://github.com/MohammedAqeelYousuf/Smart-Connect-Portal.git
cd smartcon
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Start JSON Server (for mock backend)

```bash
npx json-server --watch backend/mock-db.json --port 5500
```

### 4️⃣ Run the React App

```bash
npm start
```
